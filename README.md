# GitHub Actions zum Anfassen – Begleitcode

Begleitcode zum Buch **GitHub Actions zum Anfassen** – CI/CD mit Workflows, eigenen
Runnern, Container-Releases und Supply-Chain-Sicherheit. Teil der Reihe
IT-Trainingslager von Thomas Zachmann.

Buchseite: https://it-trainingslager.de/buecher/github-actions

Der Code begleitet das Buch; Erklärungen und Übungen stehen im Buch. Die Workflows
schreibst du im Buch selbst – hier liegt nur die Anwendung, die sie bauen. Alle
Schlüssel und Passwörter sind Laborwerte – nie in Produktion verwenden.

## Inhalt

- `notes/` – Quellcode von notes-api (Go) mit Tests und Dockerfile

git clone https://github.com/thomaszachmann/github-actions-zum-anfassen.git ~/gha-lab/code
